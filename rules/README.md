# 规则模板（Rules）

> 本目录存放 OC99TOP 官方制定的规则模板，供项目、社区或活动直接套用。

---

## 目录说明

| 文件 | 说明 |
| --- | --- |
| `README.md` | 本说明文件 |
| `*.md` | 各类规则模板 |

---

## 使用方式

1. 在本目录中找到所需的规则模板；
2. 复制模板内容至你的项目；
3. 按模板中的占位符（如 `{{PROJECT_NAME}}`、`{{DATE}}`）填入实际信息；
4. 保留原始出处与版本号。

---

## 命名规范

- 文件名使用小写英文与连字符，例如 `community-rule.md`；
- 同一规则的多语言版本以 `-zh` / `-en` 等后缀区分。

---

## 署名格式

```
本文件基于 OC99TOP 官方模板（<文件名>，版本 <版本号>）制定。
来源：https://github.com/oc99top/licence
```
