## 使用方式

1. 在对应目录中找到所需文件；
2. 复制模板内容至你的项目；
3. 按模板中的占位符（如 `{{LICENSEE}}`、`{{DATE}}`、`{{PROJECT_NAME}}`）填入实际信息；
4. 保留原始出处与版本号，不得篡改许可信息。

---

## 注意事项

- 由 OC99TOP 官方正式签发的证书，以仓库 Tag / Release 版本为准；
- 引用时建议锁定具体版本（Tag 或 Commit Hash）；
- 本目录内容按「现状」提供，不构成法律意见。
