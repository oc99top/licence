# AI 使用声明（AI）

> 本目录存放 OC99TOP 官方发布的 **AI 使用声明**，用于规范 OC 在人工智能场景下的上传、生成与训练行为。

---

## 目录说明

| 文件 | 代号 | 说明 |
| --- | --- | --- |
| `README.md` | — | 本说明文件 |
| `nai.md` | `nAI` | 禁投 AI —— 禁止上传与 AI 创作 |
| `pai.md` | `pAI` | 授权 AI —— 经授权方可上传与创作 |
| `oai.md` | `oAI` | 开放 AI —— 任何情况下允许 |

---

## 三档速查

| 代号 | 上传投喂 | AI 生成 | 模型训练 | 商用 |
| --- | :---: | :---: | :---: | :---: |
| `nAI` | ✗ | ✗ | ✗ | ✗ |
| `pAI` | 需授权 | 需授权 | 需**单独**授权 | 需授权 |
| `oAI` | ✓ | ✓ | ✓ | ✓ |

> ✓ 允许　✗ 禁止　「需授权」须事先取得作者书面许可。

---

## 使用方式

1. 先选定一份**二创授权声明**（`statements/` 根目录，如 `y2nb`、`o2`）；
2. 再选定一份 **AI 声明**（本目录），两者**组合使用**；
3. 两份声明冲突时，以**更严格**者为准（`nAI` 优先）；
4. 引用时同时标注两个代号，如 `y2nb + nAI`。

---

## 组合示例

| 组合 | 含义 |
| --- | --- |
| `o2` + `oAI` | 最开放：可二创、可商用、可用 AI |
| `s2` + `pAI` | 可商用，但须署名，AI 须授权 |
| `y2nb` + `nAI` | 非商业二创，且完全禁止 AI |
