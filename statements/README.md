# 二次创作声明（Statements）

> 本目录存放 OC99TOP 官方发布的二次创作（Fan-work）声明，明确授权范围、署名要求与限制条款。

---

## 目录说明

```
statements/
├── README.md          本说明文件
├── no2.md             NO2  · 禁止二创
├── y2nb.md            y2nb · 非商业二创
├── s2.md              s2   · 声明原创二创
├── s2nb.md            s2nb · 非商声明原创二创
├── p2.md              p2   · 授权二创
├── o2.md              o2   · 开放二创
├── ai/                AI 使用声明
│   ├── nAI · 禁投 AI
│   ├── pAI · 授权 AI
│   └── oAI · 开放 AI
└── content/           可二创内容范围
    ├── occ   · 仅授权人设
    ├── ocp   · 仅授权画像
    ├── oca   · 人设 + 画像
    ├── och   · 高尚二创（默认）
    └── noooc · 保全原角色设定
```

### 一、二创授权声明（根目录）

| 代号 | 名称 | 商用 | 须署名 | 是否需授权 |
| --- | --- | :---: | :---: | :---: |
| `NO2` | 禁止二创 | ✗ | — | 任何二创均禁止 |
| `y2nb` | 非商业二创 | ✗ | ✗（不强制） | 否 |
| `s2` | 声明原创二创 | ✓ | ✓ | 否 |
| `s2nb` | 非商声明原创二创 | ✗ | ✓ | 否 |
| `p2` | 授权二创 | 视授权 | ✓ | **是** |
| `o2` | 开放二创 | ✓ | ✗（不强制） | 否 |

### 二、AI 使用声明（`ai/`）

| 代号 | 名称 | 上传 | 生成 | 训练 |
| --- | --- | :---: | :---: | :---: |
| `nAI` | 禁投 AI | ✗ | ✗ | ✗ |
| `pAI` | 授权 AI | 需授权 | 需授权 | 需单独授权 |
| `oAI` | 开放 AI | ✓ | ✓ | ✓ |

### 三、可二创内容范围（`content/`）

| 代号 | 限定内容 |
| --- | --- |
| `occ` | 仅授权使用 OC 人设（文字设定） |
| `ocp` | 仅授权使用 OC 画像（视觉形象） |
| `oca` | 授权人设和画像 |
| `och` | 高尚二创（内容底线，**默认适用**） |
| `noooc` | 保全原角色设定（禁止 OOC） |

> 三类声明**组合使用**，例如 `y2nb + nAI + occ + noooc`；冲突时以更严格者为准。

---

## 声明应包含的要素

1. **授权范围**：允许与禁止的二次创作类型；
2. **署名要求**：必须保留的署名与出处信息；
3. **使用限制**：商业化、改编、再分发的边界；
4. **免责条款**：责任划分与风险提示。

---

## 使用方式

1. 从三类声明中**各选一项**组合使用，例如 `o2 + pAI + oca + och`；
2. 在遵守对应声明条款的前提下进行修改与再分发；
3. 修改后的版本须显著标注「非官方版本」；
4. 不得删除或篡改原作者署名与许可信息；
5. 组合内条款冲突时，以**更严格**者为准。
