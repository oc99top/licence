# 二次创作声明（Statements）

> 本目录存放 OC99TOP 官方发布的二次创作（Fan-work）声明，明确授权范围、署名要求与限制条款。

---

## 目录说明

| 文件 | 说明 |
| --- | --- |
| `README.md` | 本说明文件 |
| `*.md` | 各类二创声明文本 |

---

## 声明应包含的要素

1. **授权范围**：允许与禁止的二次创作类型；
2. **署名要求**：必须保留的署名与出处信息；
3. **使用限制**：商业化、改编、再分发的边界；
4. **免责条款**：责任划分与风险提示。

---

## 使用方式

1. 在遵守对应声明条款的前提下进行修改与再分发；
2. 修改后的版本须显著标注「非官方版本」；
3. 不得删除或篡改原作者署名与许可信息。
