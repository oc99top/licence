# 可二创内容范围（Content）

> 本目录存放 OC99TOP 官方发布的 **内容范围限定**，用于明确「可以用 OC 的哪一部分、演绎到什么程度」。
> 本目录文件**不单独生效**，须与 `statements/` 根目录的二创授权声明配合使用。

---

## 目录说明

| 文件 | 代号 | 限定内容 |
| --- | --- | --- |
| `README.md` | — | 本说明文件 |
| `occ.md` | `occ` | 仅授权使用 **OC 人设**（文字设定） |
| `ocp.md` | `ocp` | 仅授权使用 **OC 画像**（视觉形象） |
| `oca.md` | `oca` | 授权 **人设 + 画像** |
| `och.md` | `och` | **高尚二创**（内容底线，**默认适用**） |
| `noooc.md` | `noooc` | **保全原角色设定**（禁止 OOC） |

---

## 五档速查

| 代号 | 人设 | 画像 | 内容底线 | 是否改动设定 |
| --- | :---: | :---: | :---: | :---: |
| `occ` | ✓ | ✗ | 默认 `och` | 视 `noooc` 而定 |
| `ocp` | ✗ | ✓ | 默认 `och` | 视 `noooc` 而定 |
| `oca` | ✓ | ✓ | 默认 `och` | 视 `noooc` 而定 |
| `och` | — | — | 强制适用 | 不涉及 |
| `noooc` | — | — | — | **禁止** |

> ✓ 允许　✗ 禁止　`och` 与 `noooc` 为**叠加项**，可与 `occ` / `ocp` / `oca` 同时生效。

---

## 默认规则

1. **未指定内容范围时，默认适用 `och`（高尚二创）**；
2. 未指定人设 / 画像范围时，默认**均不授权**，须明确选择；
3. 多份文件叠加时，冲突部分以**更严格**者为准。

---

## 使用方式

1. 选定授权声明（如 `o2`）与 AI 声明（如 `nAI`）；
2. 再叠加所需的内容范围（如 `occ` + `noooc`）；
3. 引用时完整标注，如：`o2 + nAI + occ + noooc`。

---

## 组合示例

| 组合 | 含义 |
| --- | --- |
| `s2` + `oca` | 可商用、须署名、人设与画像都能用 |
| `y2nb` + `occ` + `noooc` | 非商业、只能用文字人设、且不得 OOC |
| `o2` + `ocp` + `och` | 开放二创，只能用画像，内容须健康向上 |
